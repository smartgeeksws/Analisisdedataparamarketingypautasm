# Análisis de datos para marketing y pauta — SM

Repositorio de trabajo para analizar marketing, Meta Ads y resultados comerciales de SM Solutions Migratorios (nombre comunicado por el usuario; razón social por confirmar).

## Objetivo
Diseñar una estrategia sustentada en datos para triplicar la eficiencia publicitaria, generar prospectos calificados y mejorar los cierres. El histórico solicitado comienza en mayo de 2026; los datos publicitarios recibidos hasta ahora cubren julio–23 de octubre de 2026.

## Forma de trabajo
Actualizar estos Markdown al recibir información relevante. Registrar periodo y fuente; distinguir datos observados, declaraciones del usuario, cálculos e hipótesis. No sustituir datos faltantes por estimaciones sin identificarlas. Preservar el histórico de correcciones mediante Git.

El usuario enviará información por partes. El diagnóstico integral y la estrategia se formularán cuando confirme que terminó la entrega. Los análisis parciales solicitados se documentarán como preliminares.

No incorporar información personal de clientes ni expedientes legales individuales: este repositorio documenta marketing y resultados agregados.
